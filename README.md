# 澳門海岸線｜古今地圖重疊對照

澳門半島、氹仔、路環歷史土地演變及地圖重疊工具。

## 網站功能

- 官方32個年份土地輪廓：1912、1936、1957、1975、1986、1991、1996、1999，以及2000至2023年。
- 9幅歷史原圖，列明來源、年份及覆蓋範圍。
- OpenStreetMap街道與Esri衞星／航空影像切換。
- 透明度重疊、左右拉桿、地點快捷定位及點選位置查詢。
- 橫琴澳大校區從填海比較範圍剔除，另列管理範圍。

## 使用與維護

`index.html` 是完整自包含版本，可直接開啟，亦適用GitHub Pages。基本地圖與歷史圖已內置；高解像網上底圖需要連線。

`source.zip` 保留模組化源碼、地圖資產、處理腳本及來源紀錄。解壓後以靜態HTTP伺服器提供 `dist/` 即可。處理腳本內的工作目錄需按本機位置調整；原始官方API查詢結果應按來源紀錄重新下載。

## 資料與限制

資料整理：2026-10-29。官方演變輪廓截至2023年；現代底圖擷取時間不等於實測或影像拍攝日期。1912年不代表完全未填海，輪廓差異亦可能包括淤積、水域處理及測繪差異；首次出現於某年快照不等於確切填海年份。不能作地籍、工程或法律界線判定。
